# 🏗️ ERP «Цемент» — Корпоративная система управления производством, складом и логистикой

Промышленная веб-платформа для автоматизации оптовой торговли цементом, управления заводскими квотами (тикетами), контроля остатков в силосах, весового контроля автотранспорта, финансовой кассы и аудита безопасности.

---

## 🔑 Учетные данные по умолчанию (Администратор)

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **URL входа** | `http://localhost:5001` (или ваш домен) | Главный интерфейс входа |
| **Логин** | `admin` | Главный администратор системы |
| **Пароль** | `admin2026!` | Полный доступ (управление пользователями, аудит, бэкапы) |

> 💡 **Другие предустановленные сотрудники:**
> - Оператор склада: логин `operator` / пароль `operator123`
> - Главный бухгалтер: логин `accountant` / пароль `accountant123`

---

## 🚀 Ключевые возможности системы

1. **Складской комплекс и Силосы**:
   - Учет насыпного цемента (марки М400, М500, Сульфатостойкий) и тарированного в мешках по 50 кг.
   - Защита от пересортицы и программный запрет отгрузки при нехватке товара.
   - Визуальный контроль вместимости силосов и предупреждения о неснижаемом остатке.

2. **Биржевые квоты заводов (Тикеты)**:
   - Прямая интеграция учета квот с заводов (Кизилкумцемент, Бекабадцемент, Алмалык).
   - Прямая отгрузка клиенту без завоза на склад.
   - Возврат неиспользованного остатка квоты на брокерский счет в один клик.

3. **Продажи, ТТН и Логистика**:
   - Оформление сделок с разделением на самовывоз и доставку транспортом предприятия.
   - Автоматический расчет логистических тарифов за тонну.
   - Мгновенная печать чистых бланков ТТН и накладных.

4. **Финансы и Кассовая книга**:
   - Мультивалютный учет (UZS / USD) с фиксацией курса на момент операции.
   - Контроль дебиторской задолженности клиентов и удобный механизм погашения долгов.
   - Анализ прибыльности и учет путевых расходов автопарка (газ, ГСМ, запчасти, суточные).

5. **Безопасность и Аудит действий (Activity Log)**:
   - Разграничение ролей (Администратор, Оператор склада, Бухгалтер, Наблюдатель).
   - Ведение непрерывного журнала действий: фиксация входов, создания сделок, изменений цен с привязкой к дате, пользователю и IP-адресу.
   - Экспорт журнала аудита в CSV.

6. **Резервное копирование и отказоустойчивость**:
   - SQLite в режиме **WAL (Write-Ahead Logging)** с гарантией ACID-транзакций.
   - Выгрузка горячего бэкапа базы данных в один клик через `GET /api/backup`.

---

## 🛠️ Технологический стек

- **Backend**: Node.js, Express, `better-sqlite3`, WAL mode, REST API.
- **Frontend**: React 18, Vite, Tailwind CSS, Three.js (интерактивная 3D-модель), Lucide Icons, Recharts.
- **Архитектура**: Single-Port Production Serving (Express раздает и API, и собранный SPA-фронтенд).

## 📦 Быстрый запуск на сервере (On-Premise / VPS)

### Вариант 1: Развертывание через Docker (Рекомендуемый)

Установите Docker и Docker Compose на сервер (Ubuntu/Debian), затем выполните:

```bash
# 1. Клонируйте репозиторий
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd ERP

# 2. Запустите контейнер в фоновом режиме
docker compose up -d --build

# 3. Проверьте статус
docker compose ps
```

Приложение будет доступно по адресу: `http://IP_СЕРВЕРА:5001`. База данных сохраняется в папке `./backend/data`.

---

### Вариант 2: Классическое развертывание (Node.js + PM2 + Nginx)

#### 1. Установка Node.js и инструментов сборки:
```bash
sudo apt update && sudo apt install -y curl build-essential python3
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
```

#### 2. Клонирование и установка зависимостей:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> erp
cd erp

# Установка зависимостей
npm run install:all

# Сборка оптимизированного фронтенда
npm run build
```

#### 3. Запуск через PM2:
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

#### 4. Настройка Nginx и SSL (пример конфигурации `/etc/nginx/sites-available/erp`):
```nginx
server {
    server_name erp.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Подключение SSL сертификата:
```bash
sudo certbot --nginx -d erp.yourdomain.com
```

## 💾 Резервное копирование по расписанию (Cron)

Для автоматического ежедневного бэкапа базы добавьте задачу в cron:
```bash
crontab -e
```
Добавьте строку (бэкап каждый день в 02:00):
```cron
0 2 * * * curl -s http://127.0.0.1:5001/api/backup -o /var/backups/erp_cement_$(date +\%F).sqlite
```
